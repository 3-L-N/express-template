# Express.js Website Template

A basic Express website that can be easily added to when making a new project

## Set up development environment

Make sure your IDE has extensions for ESLint and Prettier and set them up to automatically show errors and format code.

You can use the `.devcontainer` extension in VSCode to automatically install dependencies and prepare .env, or you could do it manually.

1. Install dependencies (Node 26 and npm):

   ```sh
   npm install
   ```

2. Copy `.env.example` to `website/.env` and then modify it if you need to

3. Start in development mode so that it will restart once you change files.

   ```sh
   npm run dev
   ```

4. Open the outputted URL in a web browser
