# Express.js Website Template

A basic Express website that can be easily added to when making a new project


## Set up development environment

You can use the `.devcontainer` in VSCode to automatically install dependencies and prepare .env, or you could do it manually:

1. Install dependencies (Node26, pnpm and required packages)

2. Copy `.env.example` to `.env` in the root directory and then modify it as needed

3. Start in development mode so that it will restart once you change files.

```sh
pnpm run dev
```

4. Open the outputted URL in a web browser
